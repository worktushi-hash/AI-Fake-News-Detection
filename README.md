# AI-Powered Fake News Detection for Regional Languages

A project to investigate and develop a text-based fake news detection system for English, Hindi, and Marathi.

## Current Scope
- Multilingual text classification
- Fake and real news labels
- Dataset inspection and preprocessing
- Model development and evaluation
- Explainability for model predictions
- Basic URL-based article extraction (planned for V1)

## Technology Stack
- Frontend: React.js
- Backend: FastAPI
- Database: PostgreSQL and MongoDB
- Models: Classical machine learning baselines and transformer models

## Project Status
Dataset inspection and validation.

## Repository Structure
- `data/`: Local datasets and processing outputs
- `scripts/`: Dataset audit and preprocessing scripts
- `reports/`: Audit results and evaluation reports
- `docs/`: Project documentation

## Data and Reproducibility
Original datasets are kept outside version control until their
contents, licensing, and suitability have been reviewed.
No model performance results will be reported until experiments
have actually been conducted.
